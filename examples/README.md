# Local numerical example

These files were generated by the implemented serial solver on 27 October 2026:

```bash
./build/heat_serial --nx 128 --ny 128 --steps 2000 --case heated_top --output outputs/serial.csv
python scripts/plot_temperature.py outputs/serial.csv --output outputs/temperature.png --vmin 20 --vmax 100
```

- `temperature.csv`: the 130-by-130 final field, including fixed physical boundaries.
- `temperature.png`: a heatmap of that field.
- `validation_summary.json`: a compact record of completed local numerical checks.

Defaults: a unit square, alpha 1, cfl 0.8, initial interior 20°C, top 100°C and other edges 20°C. Final time is approximately 0.024037 model time units.

This is a synthetic numerical demonstration, not measured material behavior or an Atlas/Vanda performance result. See [verification.md](../docs/verification.md) for the actual validation scope.
