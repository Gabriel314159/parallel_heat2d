# AI usage

- **OpenAI ChatGPT** helped choose the project topic and drafted the initial repository scaffold (documentation, configuration and build skeleton).
- **Anthropic Claude** (Claude Sonnet 5.5 and Claude Opus 5.5) drafted most of the model design, the serial, MPI + OpenMP and GPU solvers, the 3D pigment model, the tests, the benchmark and job scripts, and parts of the report text; it also reviewed the 3D Poisson benchmark and model B and helped merge the branches.

The team chose the model, the experiments and the final design, and checked all AI-generated code by running the unit tests and the serial/parallel correctness checks. All performance results come from runs on Vanda submitted by the team.
