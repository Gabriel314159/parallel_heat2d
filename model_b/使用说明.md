# Model B 压力与三维颜料输运

这一版在每个时间步更新三维速度、求解压力 Poisson 方程、修正速度，
并输运颜料。默认表层风力随深度变化，竖直速度可以非零。
支持串行 CPU 和 MPI＋OpenMP，支持沿 x、y、z 切块。

压力求解使用 Neumann 边界、零均值约束和 CG，与原先独立 Poisson
实验的 Dirichlet 问题不同。旧数据应保留在原实验中，Model B 单独记结果。
本包没有 GPU 压力投影实现。

## 先在 Vanda 做验证

先用 Mac 终端把压缩包上传到 Vanda 的 home 目录。然后在 Vanda 执行：

```bash
mkdir -p ~/model_b_test
cd ~/model_b_test
unzip ~/model_b_pressure_3d.zip
cd model_b_pressure_3d
qsub vanda_smoke.pbs
```

提交脚本已填写 `personal-sihan.wan`。该作业使用单节点 16 个 CPU 核，
先检查压力方程、投影、动量离散、质量守恒以及串并行一致性，再分别用
串行和 4 个 MPI 进程 × 2 个线程计算 100 个时间步。
任何步骤失败，作业会返回非零退出码。

成功后查看（把 `JOB_ID` 替换成包含 `.stdct-mgmt-02` 的完整作业号）：

```bash
qstat -fx JOB_ID
cat results/JOB_ID/validation/status.json
cat results/JOB_ID/smoke/summary.csv
```

`summary.csv` 是运行汇总，`raw.csv` 是每次运行的完整指标。
`*_trace.csv` 记录每步压力残差、散度、CG 次数、质量和竖直速度。
`*_field.csv` 给出最终浓度、压力势和三个面的速度，可用于作图。

## 验证通过后做一个正式运行

```bash
qsub vanda_run.pbs
```

这个作业使用 32 个 CPU 核，4 个 MPI 进程 × 8 个线程，
`64 × 64 × 32` 网格、100 步、无 spin-up，预热一次后测量三次。
这是完整模型的运行成本实验，尚不是多节点加速实验。

结果在：

```text
results/JOB_ID/model_b/raw.csv
results/JOB_ID/model_b/summary.csv
```

在 Mac 终端下载到桌面：

```bash
scp sihan.wan@vanda.nus.edu.sg:~/model_b_test/model_b_pressure_3d/results/JOB_ID/model_b/summary.csv "$HOME/Desktop/model-b-summary.csv"
```

## 已做的本地检查

`local_evidence/`（未收入本仓库）中的结果来自 Mac，小网格正确性测试，不是 Vanda 性能数据。
压力和动量空间离散接近二阶，串并行的浓度、压力和速度逐点一致到容差范围内。
还有一次 `32 × 32 × 16` 网格、100 步的串行／并行完整模型运行。

压力变量 `phi` 是投影过程中使用的运动学压力势。AB 时间推进下，它代表
该时间步的有效压力贡献，不能直接宣称为高阶准确的瞬时物理压力。
完整方程、边界条件、误差标准和计时定义见 `README.md`。
